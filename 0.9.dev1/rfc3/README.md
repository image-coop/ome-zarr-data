Real-world datasets meant to demonstrate what [RFC-3] makes possible.

Both datasets are available through https at:

```
https://test-bucket.image.coop/rfc3/CP-Ti-abnormal-grains.zarr
```

and

```
https://test-bucket.image.coop/rfc3/flim-tmr31-3-reduced64.ome.zarr
```

For further synthetic datasets, see the [clbarnes/ome-zarr-rfc3-data] repo.

[RFC-3]: https://ngff.openmicroscopy.org/rfc/3/
[clbarnes/ome-zarr-rfc3-data]: https://github.com/clbarnes/ome-zarr-rfc3-data
